# Maintainers

| Maintainer | Role |
| --- | --- |
| [@slchris](https://github.com/slchris) | Founding maintainer |

The current single-maintainer state is a continuity risk, not a claim of mature
community governance. Production operators should require independent review
for identity, signing, storage, scheduler, IaC, and release changes until the
maintainer group expands.

Maintainer responsibilities and the process for changing this list are defined
in [GOVERNANCE.md](GOVERNANCE.md).
